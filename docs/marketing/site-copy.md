## FAQ

### What is paullm-ssh?

paullm-ssh is a native SSH terminal and SFTP client for iPhone, iPad, and Apple Silicon Mac. It helps you connect to servers, browse remote files, run terminal sessions, and keep server metadata synced across Apple devices.

### Is paullm-ssh useful for vibe coding?

Yes. paullm-ssh is designed for developers who run coding agents and remote CLIs over SSH. You can prepare a Mac as an SSH host, start recognizable Claude, Codex, OpenCode, Antigravity, or tmux sessions, and reconnect from another Apple device.

### Which connection methods are supported?

paullm-ssh supports standard SSH, Mosh, Tailscale SSH, and Cloudflare Access. SSH credentials, keys, passphrases, and service tokens are stored in Keychain when required.

### How does iCloud sync work?

Server and workspace metadata sync through CloudKit. Secrets such as passwords and private keys are stored in Keychain rather than synced as raw CloudKit records.

### Does paullm-ssh include remote files?

Yes. paullm-ssh includes an SFTP-backed remote file browser with directory navigation, previews, upload, download, export, rename, move, delete, new folder, permission editing, and conflict handling.

### What terminal engine does paullm-ssh use?

paullm-ssh uses Ghostty terminal technology through GhosttyKit for fast, accurate terminal rendering.

### Does paullm-ssh work on iPad?

Yes. paullm-ssh works on iPhone, iPad, and Mac. The iOS version includes a terminal keyboard accessory with Esc, Tab, Ctrl, arrows, function keys, and custom shortcuts.

### What are the system requirements?

paullm-ssh requires iOS 16.1 or later, macOS 13.3 or later, and Apple Silicon on Mac.

### What is included in Free vs Pro?

Free includes 1 workspace, 3 servers, and 1 connection tab. Pro unlocks unlimited workspaces, servers, tabs, custom environments, priority support, and future features.
