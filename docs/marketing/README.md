# Marketing and Site Content

This folder is the source copy pack for the paullm-ssh marketing site.

- `site-copy.md` contains homepage-ready copy, positioning, CTAs, FAQs, SEO text, and alternate headlines.
- `technical-content.md` contains technical page copy for the site, including architecture, security, sync, terminal, remote files, and AI coding workflows.
- `feature-inventory.md` groups app features into product messaging themes so design and implementation can pull from one list.

The live site currently lives in `web/`. Keep this folder copy-first and design-agnostic so the website can evolve without burying messaging inside components.
